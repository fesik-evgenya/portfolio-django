1. Общие положения

Настоящая Политика конфиденциальности персональных данных (далее - Политика) разработана в соответствии с Федеральным законом от 27.07.2006 № 152-ФЗ "О персональных данных" и определяет порядок обработки персональных данных и меры по обеспечению безопасности персональных данных, предпринимаемые Фесик Евгенией (далее - Оператор).

Использование сайта fesik-dev.ru означает безоговорочное согласие пользователя с настоящей Политикой и указанными в ней условиями обработки его персональной информации.

Важно: Политика применяется ко всей информации, которую Оператор может получить о пользователях во время использования ими сайта, программ и продуктов.

2. Основные понятия

В настоящей Политике используются следующие основные понятия:

  • Персональные данные - любая информация, относящаяся к прямо или косвенно определенному, или определяемому физическому лицу;
  • Обработка персональных данных - любое действие (операция) с персональными данными, включая сбор, запись, систематизацию, накопление, хранение, уточнение, извлечение, использование, передачу, обезличивание, блокирование, удаление, уничтожение персональных данных;
  • Конфиденциальность персональных данных - обязательное для соблюдения требование не допускать их распространения без согласия субъекта персональных данных или иного законного основания;
  • Cookies - небольшие текстовые файлы, размещаемые на устройстве пользователя для анализа поведения на сайте и хранения пользовательских настроек;
  • Субъект персональных данных - физическое лицо, к которому относятся персональные данные.

  • Данные систем аналитики

4. Цели обработки данных

Персональные данные обрабатываются в следующих целях:

  • Обработка заявок: Для связи с пользователями, ответов на их запросы и консультаций по услугам разработки
  • Исполнение договоров: Для заключения, исполнения и сопровождения договоров на разработку сайтов и приложений
  • Информирование: Для отправки информации о новых услугах, акциях и изменениях в работе сайта
  • Аналитика и улучшение: Для проведения статистических исследований, анализа пользовательского поведения и улучшения функциональности сайта
  • Безопасность: Для обеспечения безопасности сайта, предотвращения мошенничества и защиты прав пользователей
  • Персонализация: Для предоставления персонализированного контента и рекомендаций

5. Правовые основания обработки

Обработка персональных данных осуществляется на основе следующих правовых оснований:

Согласие субъекта

На основании явно выраженного согласия пользователя на обработку его персональных данных

Исполнение договора

Для заключения и исполнения договора, стороной которого является субъект персональных данных

Выполнение закона

Для выполнения обязанностей, установленных законодательством Российской Федерации

Законные интересы

Для защиты законных интересов Оператора при соблюдении прав и свобод субъектов данных

6. Порядок сбора данных

Сбор персональных данных осуществляется следующими способами:

  • Формы обратной связи: Через контактные формы на сайте для запросов и заявок
  • Заказы решений: При оформлении заказа на готовые решения в разделе "Магазин решений"
  • Email-рассылка: При подписке на новостную рассылку и обновления
  • Договоры: При заключении договора на оказание услуг веб-разработки
  • Автоматический сбор: Через системы аналитики (cookies, Яндекс.Метрика, Google Analytics)
  • Переписка: В ходе переписки по электронной почте или в мессенджерах

7. Использование файлов cookie

Сайт использует следующие типы cookie-файлов для улучшения работы и анализа пользовательского поведения:

Обязательные

Необходимы для работы основных функций сайта, без которых сайт не может нормально функционировать

Аналитические

Используются для сбора статистики о посещениях и анализе пользовательского поведения

Функциональные

Позволяют запоминать пользовательские настройки и предпочтения

Согласие на использование cookies

При первом посещении сайта пользователю показывается уведомление об использовании cookies. Продолжая использование сайта после принятия уведомления, пользователь соглашается на обработку cookies в соответствии с настоящей Политикой.

Управление cookies

Пользователь может в любой момент отозвать свое согласие, очистив cookies в настройках браузера или обратившись к Оператору по указанным контактам.

Как управлять cookies в популярных браузерах:

  • Google Chrome: Настройки → Конфиденциальность и безопасность → Файлы cookie
  • Mozilla Firefox: Настройки → Приватность и защита → Файлы cookie
  • Safari: Настройки → Конфиденциальность → Управление данными веб-сайтов
  • Microsoft Edge: Параметры → Конфиденциальность и безопасность → Файлы cookie

8. Передача данных третьим лицам

Персональные данные пользователей не передаются третьим лицам, за исключением следующих случаев:

  • При получении явного согласия пользователя на передачу данных
  • По требованию уполномоченных государственных органов в рамках установленной законодательством процедуры
  • Для исполнения договорных обязательств (например, для регистрации домена или хостинга)
  • При использовании анонимизированных данных для аналитических сервисов
  • В случае реорганизации или продажи бизнеса с обязательным уведомлением пользователей

Используемые сторонние сервисы

Для обработки данных могут использоваться следующие сервисы:

  • Яндекс.Метрика - веб-аналитика для анализа посещаемости сайта
  • Google Analytics - анализ пользовательского поведения и трафика
  • Email-сервисы - для отправки уведомлений и рассылок
  • Хостинг-провайдеры - для хранения данных сайта

Все сервисы обеспечивают необходимый уровень защиты данных в соответствии с их политиками конфиденциальности.
